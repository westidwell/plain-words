# Plain Words Pro

Pro is $1/month (launch price). It isn't open yet: star or watch this repo to hear when it opens.

The free page stays free and complete: paste, clean, review every change, copy or save. Pro is for people who clean a lot of documents, or a whole team's.

| Pro feature | What it does |
| --- | --- |
| **Word files in and out** | Open a .docx and get it back cleaned, with every change as a tracked change. |
| **Change report as a Word document** | A one-page report of every swap, check and flag, ready to send with the draft. |
| **Your own phrase bank** | Add your own rules, switch any rule off, and import or export the list. |
| **Team phrase bank** | One shared list of rules and words to leave alone for everyone on a team. |
| **Clean a whole folder** | Run every file in a folder at once and get one summary back. |

These features are reserved for Pro, so pull requests that add them will be closed with a pointer here. See [CONTRIBUTING.md](CONTRIBUTING.md) for what's welcome.
